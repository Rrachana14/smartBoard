✋🖌️ Smart Drawing Board using Hand Gesture Recognition

A virtual drawing board powered by OpenCV, MediaPipe, and Tkinter, allowing users to draw and erase on a canvas using hand gestures captured from a webcam. No mouse or touch required!

📌 Features
🖐️ Real-time hand tracking using MediaPipe.

🖍️ Draw using index finger gesture.

🎨 Change color with virtual buttons (Red, Green, Black).

🧽 Erase using three-finger gesture (Index, Middle, Ring).

👁️ Eraser preview overlay.

✋ Automatically pauses drawing when fingers are pinched (index + thumb).

Requirement

pip install opencv-python mediapipe pyautogui
